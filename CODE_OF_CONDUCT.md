# Uorqui community code of conduct

[English](CODE_OF_CONDUCT.md) · [Português (Brasil)](CODE_OF_CONDUCT.pt-BR.md)

## Our commitment

Uorqui welcomes contributors with different backgrounds, experience levels and viewpoints. We aim for a respectful, collaborative environment in repository issues, pull requests, discussions and other official project spaces.

## Expected behavior

- Be constructive and assume good intent while addressing concrete mistakes.
- Make technical criticism specific to ideas, designs or code rather than individuals.
- Respect privacy and personal boundaries; seek consent before sharing private conversations or screenshots.
- Help newcomers navigate decisions and documentation without gatekeeping.
- Give credit for work and respect open-source and third-party licenses.

## Unacceptable behavior

Harassment, discrimination, personal attacks, sexualized harassment, threats, doxxing, stalking, spam, deliberate disruption or publication of private information without consent are not acceptable.

## Enforcement

Maintainers may edit or remove inappropriate content, request behavioral changes, restrict participation or block accounts from project spaces when necessary. Decisions should consider the severity, repetition and impact of the behavior.

## Reporting

Report conduct concerns privately to a maintainer using a contact method they explicitly provide; do not share sensitive evidence in public issues. If the only available channel is public, avoid posting personal information. There is no guaranteed response timeframe at this early stage.

This code of conduct applies to official Uorqui development spaces, not unrelated third-party services.
