# Uorqui · versão demonstrativa

Esta branch contém uma apresentação interativa e independente do Uorqui.

## Conteúdo da demonstração

- painel executivo com métricas de participação e engajamento;
- comunidades públicas e privadas;
- feed com posts, perguntas, comunicados, enquetes e eventos;
- respostas, curtidas, exclusão de respostas e conclusão de assuntos;
- central de vagas internas e públicas;
- notificações e atividades recentes;
- navegação responsiva para desktop e celular.

Todos os nomes, números e conteúdos são fictícios. A demonstração não usa login, Firebase, Firestore, R2 ou dados do ambiente de produção.

## Executar localmente

```bash
npm install
npm run dev
```

A entrada demonstrativa está em `src/DemoApp.tsx` e os estilos em `src/demo.css`.
