# UI kit

[English](../en/ui-kit.md) · [README](../../README.pt-BR.md)

Os tokens editáveis dos temas claro e escuro do shadcn/ui ficam em [styles.css](../../apps/web/src/styles.css). Importe os tokens no tweakcn ao alterar a paleta e aplique os valores exportados no mesmo arquivo. O espaço de trabalho, os diálogos e os formulários compartilham esses tokens.

| Token | Claro | Escuro |
| --- | --- | --- |
| Background | `#f5f7f6` | `#111b18` |
| Foreground | `#172b25` | `#e8f4ef` |
| Card | `#ffffff` | `#172420` |
| Primary | `#176450` | `#99e1c8` |
| Accent | `#dbece5` | `#23463a` |

A lista de canais usa uma barra lateral compacta no desktop e uma tela própria no celular. Os tópicos ficam ao lado da conversa quando há espaço. Use Enter para enviar e Shift+Enter para quebrar a linha. Os diálogos oferecem foco pelo teclado e podem ser fechados com Esc.
